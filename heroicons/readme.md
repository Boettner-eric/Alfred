# Heroicons Workflow

Search for the perfect heroicon and copy its name to the clipboard

# Setup

- clone the official heroicons repo (or run hero in alfred and hit enter)

#### Mods

- default -> show/copy outline version of icon
- `⌘` -> show/copy solid version of icon
- `⌥` -> show/copy solid 16px version
- `⌃` -> show/copy solid 20px version
